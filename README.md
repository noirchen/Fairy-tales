# 安德鲁·朗格彩色童话全集

《安德鲁·朗格彩色童话》系列是世界著名童话集，但其中文版翻译时间较早，其中错误较多，且目前只有扫描版留存。近年来也有所谓“全集”重新出版，但都是节选版，语言相对简单，甚至一些名篇都不在其中。

本项目以 1997 年上海科学普及出版社版《安德鲁·朗格彩色童话全集》为底本，由百度 PaddleOCR 电子化，转为 markdown 格式后，更换低分辨率的插图。用 AI（Workbuddy 的 Balanced 模式）寻找不符合现代规范汉语的用法，经人工判断适度修改（例如“倒楣” → “倒霉”），再和古登堡英文原本对照，修正错译（例如淡紫色童话中《得到奥尔温》《老鼠得救》中，野猪 wild boar 被译作熊）、漏译等，以脚注形式标出，在不影响儿童对故事理解程度的基础上进行修正。

由于原书年代久远，文中不可避免带有一些时代特色，需要读者自行鉴别。另外，一些超出儿童理解范围的历史地理名词，当初翻译成中文时就被简化了，这里也视情况以脚注形式标出。
